# Quizzy — первая версия

Quizzy — браузерная командная/многопользовательская викторина в ярком стиле.

## Что уже работает
- ведущий создаёт комнату с шестизначным PIN-кодом;
- автоматически создаётся QR-код для входа игроков;
- игроки заходят с телефонов, вводят имя и выбирают персонажа;
- ведущий запускает викторину;
- вопросы идут с таймером на 15 секунд;
- правильный ответ приносит до 1000 баллов: учитываются правильность и скорость;
- таблица лидеров обновляется в реальном времени;
- в конце показывается победитель.

## Запуск на компьютере

Нужен Node.js 18 или новее.

1. Распакуй архив.
2. Открой терминал в папке `quizzy`.
3. Выполни:

   ```bash
   npm install
   npm start
   ```

4. Открой `http://localhost:3000`.

## Подключение телефонов
Для настоящего подключения игроков через QR-код сайт должен быть доступен по общему адресу в интернете. После публикации на хостинге QR-код будет вести на опубликованный сайт.

Для теста в одной Wi-Fi сети можно открыть сайт по локальному IP компьютера (например, `http://192.168.1.10:3000`), если firewall разрешает входящие подключения. QR-код будет использовать этот адрес.

## Важно
Это стартовый MVP: комнаты хранятся в памяти сервера и исчезают при перезапуске. Для публичного использования позже стоит добавить постоянное хранение, защиту от спама, панель создания собственных викторин и модерацию имён.
